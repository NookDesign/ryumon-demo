# 龍門精舎 トップページ（リニューアル提案デモ）

CrowdWorks のWebサイトリニューアル案件への提案用に、Nook Design が制作したデモです。
**龍門精舎の公式サイトではありません。** 経歴・歴史・実績・口コミ・料金は掲載していません。

## ファイル構成

```
ryumon-seisha-demo/
├── index.html              … トップページ本体
├── .nojekyll               … GitHub Pages でファイルをそのまま公開するための空ファイル
├── README.md               … この説明書
└── assets/
    ├── style.css           … デザイン（色・文字・余白は先頭の :root でまとめて変更可）
    ├── script.js           … メニュー開閉・スクロール表示・画像エラー対策
    └── images/
        ├── favicon.svg         … ブラウザのタブのアイコン（仮）
        ├── hero-gate.svg       … メインビジュアルの門と月のイラスト（Nook Design 制作）
        └── pattern-lattice.svg … 背景の格子模様（韓国伝統の窓格子をイメージ・Nook Design 制作）
```

## 仕様

| 項目 | 内容 |
| --- | --- |
| 配色 | 黒 `#120d0c`・深い赤 `#7d1720`・ゴールド `#b8975a`・生成り `#f5f0e7` |
| 文字 | しっぽり明朝（Google Fonts・無料・OFL）。読み込めない場合は端末の明朝体 |
| 画面幅 | スマホ（320px〜）／iPad／PC。PC用のレイアウトは 960px、横並びメニューは 1100px から |
| 画像 | 自作のSVGのみ（写真・ロゴは未使用）。読み込めなくても色の背景でレイアウトは崩れない |
| 外部サービス | Google Fonts のみ。API・有料サービス・フォーム送信なし |
| 検索対策 | `noindex`（提案用デモなので検索結果に出さない） |

## 公式情報が届いたら差しかえる場所

- 紹介文・「大切にしていること」3項目（`#about`）
- 鑑定師のお写真・お名前の表記・ご経歴（`#master`）。写真は `assets/images/` に入れ、`.master__photo-frame` の中に `<img>` を追加
- 鑑定メニュー名・内容・料金・時間（`#menu`）
- 鑑定の流れ（`#flow`）／よくある質問の回答（`#faq`）
- ご予約ボタンの行き先、所在地・営業時間・地図（`#contact`）
- アメリカ向けサイトへのリンク（`.us-guide`）
- 公開時は `index.html` の `noindex` 行・デモのお知らせ・「デモ用」表示を削除

## このデモで使っていないもの

- 人物・寺院・風景の写真や生成画像（ご提供いただく公式素材のみを使う方針）
- 既存サイトの写真・ロゴ・文章の転載
- 料金・経歴・口コミ・詳しい住所・営業時間（掲載元によって記載が異なり、確認できていないため）
